# Contributing

1. Pick a ticket assigned to you in Jira (project MM) and move it to *In Progress*.
2. Create a branch from `main`: `MM-<number>-short-name`.
3. Commit with the ticket key first: `MM-15 limit cart quantity to stock`.
4. Open a pull request; one other member reviews it; then merge and move the ticket to *Done*.
5. Never commit `.env`, passwords or API keys.
